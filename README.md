## 怎么用：三步从比价到精确报价

整个流程分三步：先选地域和时长，再输入规格比价，最后补齐磁盘和带宽参数拿精确报价。

### 第一步：地域和时长都可以多选

以CADT价格计算器为例，地域和购买时长都支持多选。比如同时勾选北京、杭州、上海三个地域，时长勾上“1个月”和“3个月”，页面右侧会同时给出多种组合的价格，横向对比一眼就能看出来。

### 第二步：输入规格，列表按价格从低到高排

选完地域和时长，输入目标规格，比如4核8G，右侧会出现满足条件的候选服务器列表，排序规则是价格从低到高。想找最便宜的那台，直接看列表第一行。

多地域比价有个实际例子：同样查询 ecs.c6a.xlarge，乌兰察布最便宜，杭州和北京价格相同。但点“选择此规格”之后会发现，乌兰察布已经没有这个规格的库存了——可用区下拉列表是空的，页面同时出现红字提示“该规格未查询在（XX地域）正在售卖的可用区”。便宜和能买到是两回事，下单前记得确认可用区列表里有货。

同地域也能比不同型号：都在北京、都是4核8G，ecs.c6a.xlarge、ecs.g6a.xlarge、ecs.c6.xlarge 这些规格按价格从低到高排开，性价比差距直接摆在一起。

### 第三步：补齐四项参数，才有精确报价

只有规格和时长，算出来的只能算参考价。要拿到精确报价，还需要填四项：操作系统、系统盘和数据盘的大小及配置、公网带宽、购买数量。

官方文档给的示例是这样的：规格选 ecs.c6a.xlarge，挂一块40G系统盘、加一块100G数据盘，公网带宽1M。填完后点“询价并加入”，右侧就显示这台服务器的精确价格。如果第一步勾了两个时长，这里会分别显示“1个月”和“3个月”两个价格，方便对照。

## 常见问题

### 价格计算器支持哪些云产品？

默认打开是云服务器ECS。点“更多”可以切换：对象存储OSS、负载均衡SLB、弹性公网IP、NAT网关、Web应用防火墙、云安全中心、云数据库RDS等常用产品都能估算。

### 计算器算出的价格就是最终付款价吗？

不一定。报价受地域、计费模式和促销活动影响，官方提示实际以结算页面为准。前文g9i的21899.05元/年报价同样注明以结算页为准——拿去申请预算时留点余地。

### 固定带宽和按流量计费怎么选？

流量平稳选固定带宽，价格可控；流量波动大选按流量计费，避免为峰值买单。内网流量不用操心，同地域VPC内网通信免费。

### 海外业务能用同一个计算器吗？

用的是阿里云国际站（Alibaba Cloud）账号的话，那边提供独立的价格计算器，支持云服务器的包年包月和按量付费两种计费方式，负载均衡、轻量服务器、云数据库RDS、Redis等产品也能估算。询价前先确认自己用哪个站的账号。

一是规格族按业务场景选，别拿预算倒推配置。上表的对应关系就是官方的选型逻辑：Web服务看g系列，数据库看r系列或i系列，转码渲染看c系列，AI训练直接看GPU实例。实际配置要根据自身使用场景定，单看预算容易买偏。
